# libc

## add Functional

- [mkdtemp](../../../core/libs/prx/libc/src/TemporaryDirectories.cpp) (libc) - creates a directory and sets its mode to `0700` from a guest template whose last six characters are `X`, replacing them from host entropy, resolving the full guest path for each candidate and retrying collisions with guest errno values; the NID `Qn+tBdUwoBs` is computed from the exported name. Host filesystem permissions apply on Windows. Console behaviour on unmapped templates and collision exhaustion is not measured.
